 # Tark AI - Judge AI | Proof-Based Reasoning

Tark AI is an Offline Multi-Agent System built on Gemma 4 E4B for the Kaggle Gemma Sprint.

## Core Concept - Judge AI
Unlike normal chatbots, Tark doesn't just answer. It PROVES its answer.

**4 Agents + 1 Judge:**
1.  **Vichar Agent:** Breaks down the question logically
2.  **Khoj Agent:** Searches offline knowledge base
3.  **Tark Agent:** Debates pros/cons
4.  **Nirnay Agent:** Creates final answer with proof
5.  **Judge Agent:** Validates with score 0-10. If score < 7, it regenerates.

## Tech Stack
- Model: Gemma 4 E4B Instruct
- Offline Capable: 100% works without internet
- Language: Supports Hindi + English reasoning
- Use Case: Coding Agent, Education, Legal Reasoning

## Why Tark?
Inspired by Indian Nyaya Shastra - Every claim must have Praman (Proof).
